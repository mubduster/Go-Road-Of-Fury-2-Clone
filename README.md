# GO Road Of Fury 2 Clone
[**Road Of Fury 2**](https://www.newgrounds.com/portal/view/651061) is one of my favorite childhood flash games. This project is not made by any of the developers or endorsed by the creators of the Road of Fury games, Ivory Games. This game I purely made for learning how to make these kind of games, and is not a commercial product.

Road Of Fury 2 is a Shoot 'em Down style game, where the Player controls the Guns and Utility of the cars and uses them to get by multiple waves of enemies, to get to the end. 

This Project is a mere **"clone"** of the Game **Road Of Fury 2**, and all the assets in this were hand drawn by me with inspiration from the real game. All the code is written in **Go**, with assets made in [**BlockBench**](https://blockbench.net/). 

**This project is a WIP so it is not complete or close to complete at its current state.**



## How To Install?
To download the game go to the [**Releases**](https://github.com/mubduster/Go-Road-Of-Fury-2-Clone/releases) tab on this GitHub repository and download the appropriate version of the game according to your Operating system, from the latest release.

Once it has downloaded, locate the file and extract it to any directory you wish to install the game to.

Then to launch the game just run the executable file in the newly created folder.

## Controls
1. **Aim** - Move Mouse to the position on the screen to aim at.

2. **1**- Car 1 Ability
3. **2**- Car 2 Ability
4. **3**- Car 3 Ability
